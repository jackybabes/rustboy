ROMs are read locally by your browser — nothing is uploaded. You can also drag a .gb file onto the page. Supports no-MBC, MBC1, MBC3 and MBC5 cartridges (DMG only, no sound). The demo is blargg's cpu_instrs test ROM, which prints a result for each CPU test.
